# ForYou Gym SaaS

A professional multi-tenant fitness platform built with Django and React.

## Tech Stack
- **Backend**: Django & Django REST Framework
- **Frontend**: React (Vite & TypeScript)
- **Database**: PostgreSQL
- **Cache**: Redis
- **Reverse Proxy**: Nginx

## Getting Started

### Prerequisites
- Docker & Docker Compose

### How to Run
1. **Initialize Environment**:
   ```bash
   cp .env.example .env
   ```

2. **Start the System**:
   ```bash
   docker compose up --build
   ```

The application will be available at [http://localhost:9090](http://localhost:9090).
